# YoungLion Cast glossary

- **YoungLion Account** — The identity a person uses to sign in to Cast and manage their publishing
  accounts.
- **Publishing account** — A specific Twitch or Kick channel the signed-in person has authorized for
  publishing.
- **Scene** — The composition selected for preview or output.
- **Source** — An image, text, or capture input that can be placed in a scene.
- **Capture target** — The display, window, application, or game selected for a capture source.
- **Destination** — A publishing account selected to receive a live broadcast.
