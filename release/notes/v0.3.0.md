## YoungLion Cast 0.3.0 preview

- Edit scenes, position and crop layers, and preview capture in the Qt 6.12 desktop editor.
- Send the same H.264 video to multiple local RTMP receivers. Every target has its own connection
  and reconnect status. This first transport test uses video only and accepts IPv4 loopback targets.
- Manage Twitch and Kick publishing authorizations with the YoungLion Account integration when
  configured. Live platform broadcasting will follow once stream-key retrieval is integrated.

This is a development preview. The Linux X11 capture, local RTMP delivery and backend are tested in
CI. Physical hardware, Wayland portal behavior, and live platform accounts have separate test
requirements. The attached platform bundles are unsigned. See the source archive for the build
scripts and dependency notices. The software is GPL-3.0-or-later.
